# Changelog

## [1.2.0]

### Electron → WebView2

- Десктоп-оболочка перенесена с Electron на **WebView2** (.NET 8, WinForms):
  окно без системной рамки, ресайз за края, перетаскивание за шапку,
  запуск рендерера из встроенной Vite-сборки.
- Мост `chrome.webview.postMessage` ↔ рендерер заменил Electron IPC:
  те же методы — `settings.*`, `window.*`, `tts.*`, `overlay.*`,
  `widget.info`, `hotkeys.apply`, `clipboard.set`, `shell.openExternal`.
- Настройки хранятся в `%LOCALAPPDATA%\YawaChatHub\settings.json` (как раньше).
- Озвучка через **SAPI** (`SAPI.SpVoice`) — миграция модуля tts из Electron.
- Глобальные хоткеи через Win32 `RegisterHotKey` — работают поверх игры.
- Игровой оверлей — второе окно `CoreWebView2` поверх всех окон,
  «клик-сквозь» (`WS_EX_TRANSPARENT`), живой рендерер `#/overlay`.
- Сервер OBS-виджета на `127.0.0.1:8085` (`HttpListener` + SSE `/widget/events`).
- Трей с меню «Показать / Выход», сворачивание по «крестику» (настраивается).

### Интерфейс (1:1 от оригинала + правки по обратной связи)

- **Каналы**: модалка добавления с выбором площадки, новые карточки
  (цветная полоса, статус, зрители), починено сворачивание/разворачивание
  панели — явная кнопка-стрелка.
- **Навигация**: в рейле только «Лента» и «Чат-бот»; все настройки
  собраны под шестерёнкой (11 вкладок с поиском).
- **Авторизация бота**: крупные карточки «Войти» для Twitch и VK Play Live
  в разделе «Чат-бот» + компактный блок в панели каналов, общее состояние.
- **Переключатели**: убраны декоративные — каждый контрол сохраняется
  и влияет на поведение (лимит ленты, подсветка упоминаний, скрытие
  удалённых, сигнал перед донатом, порт виджета и др.).
- **Лента**: автоскролл привязан к id последнего сообщения — работает
  и после достижения лимита ленты.
- **Стикеры**: эмоуты по площадкам (Twitch CDN + общий набор), крупные
  стикер-сообщения, фолбэк на код при недоступной картинке.
